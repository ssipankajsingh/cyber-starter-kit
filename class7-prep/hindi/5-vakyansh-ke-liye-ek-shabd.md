## यह क्या है?

कई बार एक **लंबा वाक्यांश** (शब्दों का समूह) एक ही शब्द में कहा जा सकता है।

जैसे: *"जो ईश्वर में विश्वास रखता हो"* = **आस्तिक**

इसे **अनेक शब्दों के लिए एक शब्द** या **वाक्यांशों के लिए एक शब्द** कहते हैं। इससे भाषा छोटी और सुंदर बनती है।

## लोग (व्यक्ति)

| वाक्यांश | एक शब्द |
|---|---|
| जो ईश्वर में विश्वास रखता हो | आस्तिक |
| जो ईश्वर में विश्वास न रखता हो | नास्तिक |
| जिसका कोई शत्रु न हो | अजातशत्रु |
| जो सब कुछ जानता हो | सर्वज्ञ |
| जो कुछ न जानता हो | अज्ञानी |
| जो अपने देश से प्रेम करता हो | देशभक्त |
| जिसके माता-पिता न हों | अनाथ |
| जो पढ़ा-लिखा न हो | अनपढ़ (निरक्षर) |
| जो दूसरों का उपकार करे | परोपकारी |
| जो आज्ञा का पालन करे | आज्ञाकारी |
| जो बहुत बोलता हो | वाचाल |
| जो कम बोलता हो | मितभाषी |
| जो दूर की सोचता हो | दूरदर्शी |
| जो बहुत खर्च करता हो | अपव्ययी |
| जो कम खर्च करता हो | मितव्ययी |
| जो अपने कर्तव्य को निभाए | कर्तव्यनिष्ठ |
| जो उपकार को मानता हो | कृतज्ञ |
| जो उपकार को न माने | कृतघ्न |
| जिसका पति मर गया हो | विधवा |
| जिसकी पत्नी मर गई हो | विधुर |
| जो पैदल चलता हो | पदयात्री |

## जीव-जंतु

| वाक्यांश | एक शब्द |
|---|---|
| जो आकाश में उड़ता हो | नभचर |
| जो जल में रहता हो | जलचर |
| जो ज़मीन (थल) पर रहता हो | थलचर |
| जो मांस खाता हो | मांसाहारी |
| जो मांस न खाता हो | शाकाहारी |
| जो सब कुछ खाता हो | सर्वाहारी |

## गुण, दशा और अन्य

| वाक्यांश | एक शब्द |
|---|---|
| जिसका आदि (आरंभ) न हो | अनादि |
| जिसका अंत न हो | अनंत |
| जो कभी न मरे | अमर |
| जो दिखाई न दे | अदृश्य |
| जो आँखों के सामने हो | प्रत्यक्ष |
| जो आँखों से दूर, या सामने न हो | परोक्ष |
| जिसे गिना न जा सके | अगणित |
| जिसकी तुलना न हो सके | अतुलनीय |
| जिसे जीता न जा सके | अजेय |
| जिसे क्षमा न किया जा सके | अक्षम्य |
| जिसकी कोई उपमा न हो | अनुपम |
| जिसमें बल न हो | निर्बल |
| जो सदा रहने वाला हो | शाश्वत |

## याद रखने के तरीके

- **"अ" का खेल।** जिस शब्द में **"न हो"** या **"नहीं"** आए, उसमें अकसर शुरू में **अ** लगता है: अ-नाथ, अ-गणित, अ-दृश्य, अ-मर, अ-जेय, अ-क्षम्य।
- **"सर्व" = सब।** जो सब कुछ जाने: **सर्व**ज्ञ। जो सब कुछ खाए: **सर्व**आहारी (सर्वाहारी)।
- **"चर" = चलने वाला।** आकाश में चले: नभ**चर**। जल में: जल**चर**। थल पर: थल**चर**।
- **"आहारी" = खाने वाला।** मांस का आहारी: मांस**आहारी**। शाक (सब्ज़ी) का आहारी: शाक**आहारी**।
- **आस्तिक/नास्तिक:** *न* + *आस्तिक*। "न" यानी "नहीं" मानता।
- **समूह में याद कीजिए।** पहले जीव-जंतु वाले छह शब्द पक्के कीजिए, फिर व्यक्ति वाले।
- **कहानी बनाइए।** "एक **अजातशत्रु** राजा था, जो **दूरदर्शी** और **परोपकारी** था।" कहानी में शब्द जल्दी बैठते हैं।

## आम गलतियाँ

- **आस्तिक और नास्तिक को उलट देना।** *आ* वाला मानता है, *न* वाला नहीं मानता।
- **प्रत्यक्ष और परोक्ष को मिला देना।** प्रत्यक्ष = सामने। परोक्ष = सामने नहीं।
- **वर्तनी की गलती।** *अपव्ययी* को *अपव्यई* या *नभचर* को *नभचार* लिखना।
- **वाक्यांश अधूरा पढ़ना।** *"जो मांस न खाता हो"* (शाकाहारी) और *"जो मांस खाता हो"* (मांसाहारी) में बस "न" का अंतर है।

## संक्षेप

- लंबे वाक्यांश की जगह एक शब्द: आस्तिक, सर्वज्ञ, अनाथ, नभचर, शाकाहारी, अनंत, अमर
- "न हो" वाले वाक्यांशों में अक्सर शुरू में **अ**
- समूह बनाकर और कहानी में जोड़कर याद कीजिए
