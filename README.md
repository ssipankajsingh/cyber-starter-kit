# Cyber Starter Kit

A free, hands-on way to find out if cybersecurity, AI security or automation is for you.

It's built for students in class 10 and up. You don't need to know any coding. You need a laptop, a few evenings, and some curiosity. By the end you'll have four small security tools you built yourself, and a decent idea of what people in these jobs actually do all day.

## What's inside

| Part | What you'll make | Time | Status |
|---|---|---|---|
| [Module 0](module-0/) | Security basics, AI basics, and just enough Python to start building | ~3 hrs | Python starter ready |
| [Project 1](project-1-password-checker/) | A password strength checker that prints a report card | 2–3 hrs | Ready |
| Project 2 | A script that spots suspicious links in a list | 2–3 hrs | Coming soon |
| Project 3 | A log watcher that catches someone guessing passwords | 2–3 hrs | Coming soon |
| Project 4 | Trick a chatbot into breaking its rules, then defend it | 2–3 hrs | Coming soon |

Do them in order. Each one builds on the last.

## How it works

Every project folder has:

- a **README** that walks you through it, step by step
- **starter code** with blanks (`____`) for you to fill in
- **sample data** to test your code on
- a **solution** file, for when you're truly stuck (try first, honestly, it sticks better)

Early on, you fill in a few blanks in code that's mostly written for you. Project by project, the blanks get bigger. By Project 4 you'll be writing most of it yourself.

Every project ends with something on your screen worth a screenshot. Share it with a friend, a teacher, or on LinkedIn if you have one.

## What you need

- A laptop running Windows, macOS or Linux. Nothing fancy.
- Python 3.10 or newer. It's free, and [Module 0](module-0/python-starter/) shows you how to install it.
- A text editor. IDLE comes with Python and works fine. [VS Code](https://code.visualstudio.com/) is free and nicer once you get going.

No paid tools, no sign-ups, and no internet needed once Python is installed.

## About the sample data

Everything in the `sample_data` folders is made up for this kit: usernames, passwords, logs, links, all of it. None of it comes from a real company, school or person. Where IP addresses show up, they use ranges that are set aside for examples (like `192.0.2.x`), so they never point at anyone's real computer.

## Play fair

What you learn here is what defenders use to protect people. Only ever test things you own, or that someone has clearly given you permission to test. Trying this stuff on your school network, a friend's account or a website you don't own isn't a prank. In most countries it's a crime.

## For teachers and mentors

Answers live next to the work: `ANSWERS.md` in Module 0, and a `solution_*.py` file in each project. Each project is sized for one 2–3 hour session, or two shorter ones.
