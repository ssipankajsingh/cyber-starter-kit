# Module 0: The basics

← [Kit home](../)

About 3 hours, split into three parts. Do them in order if you can. If you're itching to write code, Part 3 works on its own.

| Part | What it covers | Time |
|---|---|---|
| 1. [Security basics](security-basics/) | How attacks actually happen, and how defenders think | ~1 hr |
| 2. [AI basics](ai-basics/) | What a chatbot really does, and why it can be tricked | ~45 min |
| 3. [Python starter](python-starter/) | Python, learned through three small security jobs | ~1 hr 15 min |

Each section ends with a quick check, a few questions or one tiny exercise, so you know it's sunk in before you move on. Answers are in the `ANSWERS.md` file in each folder.
